Charmed KServe documentation
============================

Charmed KServe deploys `KServe`_ on Kubernetes with `Juju`_. The ``kserve-controller``
charm runs the KServe control plane for ``InferenceService`` workloads, in serverless
(Knative) or RawDeployment mode, as part of `Charmed Kubeflow`_.

Project and community

Charmed KServe is an open-source project that values its community. Contributions,

* Read our `Code of conduct`_.
